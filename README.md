# titanfall2mod_no_body_no_reload

[English](#english) | [Italiano](#italiano)

## English

Unofficial add-on by **jshodanVR** for the Titanfall 2 VR campaign.

**This repository does not include CircuitLord's installer, executables, DLLs or assets. `Install.cmd` is only this add-on's patcher: it neither installs nor downloads the base VR mod.**

Obtain and install the base mod separately from **[CircuitLord's official GitHub repository](https://github.com/CircuitLord/CircuitLordVRModInstaller)**.

- Restores game-managed reloading, without manually inserting magazines or operating the bolt in VR.
- Hides the pilot's body while keeping hands, weapons and held objects visible.
- Closes and refines the wrist cuffs, without the stretched fabric remnants of the initial prototype.

**“no_reload” in the name means no manual VR reloading: it does not mean infinite ammunition and does not remove the game's reload cycle.**

### Required base mod version

| Component | Version |
| --- | --- |
| **Required base mod: CircuitLord Titanfall2VR** | **1.0.25, stable channel** |
| Reference official installer: CircuitLordVRModInstaller | **1.2.12** |
| This add-on | 1.0.1 |

**1.0.25 is the VR mod version; 1.2.12 is the installer version. They are different version numbers.** Running installer 1.2.12 alone does not guarantee that the correct mod version is installed: select Titanfall2VR 1.0.25 and check the version actually installed.

Install the game and base mod first, then launch the VR campaign at least once and confirm that it works.

For the base mod and its installer, use only the Releases section of **[the author's GitHub repository](https://github.com/CircuitLord/CircuitLordVRModInstaller)**. Neither is hosted or attached here.

The patcher also checks the exact SHA-256 hashes of the DLL and both original models. If the files differ, it stops instead of attempting to patch them. **Other versions, beta builds and already modified DLLs are not automatically supported.**

### Installation

1. Download this project using **Code → Download ZIP** and extract it completely.
2. Close Titanfall 2.
3. Run **Install.cmd (our patcher, not CircuitLord's installer)** and paste the path to the folder containing `Titanfall2.exe`.
4. Wait for the completion message, then start the game through your usual VR launcher.

Requires Windows 10/11 **x64**, PowerShell 5.1 or later, and an Internet connection on first use. No system-wide Python or Node.js installation is required: the script downloads portable runtimes and open-source libraries, with pinned versions and checksums, into the user's local application data folder. It does not change the Windows PATH and normally does not require administrator privileges.

**Check.cmd** checks compatibility without modifying the game. On first use, it may download the Python runtime alone.

The patch is applied to the `TF2VR` profile. The patcher saves the original DLL and a local installation receipt in:

```text
Titanfall2/TF2VR/titanfall2mod_no_body_no_reload.backup/
```

Locally generated models are installed as a separate add-on:

```text
Titanfall2/TF2VR/mods/titanfall2mod_no_body_no_reload/
```

### Uninstalling

Close the game and run **Uninstall.cmd**, selecting the same game folder. It restores the original DLL and removes only files generated by this add-on. If it finds files that were subsequently updated or modified, it stops rather than overwriting them.

Do not delete the backup folder before uninstalling. Portable runtimes remain in `%LOCALAPPDATA%\titanfall2mod_no_body_no_reload\runtime` and can be removed manually when no longer needed.

### What is distributed

This repository contains **patcher code, instructions, checksums and documentation**. It contains no VR mod DLL, mod executables, game models, textures or VPK archives, either original or modified.

Our patcher reads the DLL and VPK archives already present on the user's PC, generates the changes locally and creates local backups only. It does not download CircuitLord's installer, VR mod or models from this repository or any other site. The only automatic downloads are the open-source tools listed in `runtime-lock.json`. Do not upload generated files, backups or temporary working folders to GitHub.

Automatic reloading changes three calls in the compatible DLL. Hands-only geometry is generated from the two local pilot models; only wrist-rim positions and skinning weights are refined to keep the cuffs closed during animation.

### Compatibility and limitations

- Tested on a specific Titanfall2VR 1.0.25 installation and the two models identified in `compatibility.json`.
- File validation does not replace testing every headset/controller combination or every campaign sequence.
- Base mod updates may replace the DLL. Uninstall this add-on before updating; a newer base mod version requires a new compatibility assessment.
- Avoid other modifications that replace the same pilot models. The patcher does not modify saved games.

### Development

The code requires Python 3.12 and NumPy 2.3.5; VPK extraction uses Node.js and TFVPKTool 0.3.1. Runtime versions are pinned in `runtime-lock.json`. Run file-management tests with:

```text
python -m unittest discover -s tests -v
```

Public tests use synthetic files: they neither require nor include game assets.

## Italiano

Add-on non ufficiale di **jshodanVR** per la campagna VR di Titanfall 2.

**Qui non è incluso l'installer di CircuitLord, né alcun suo eseguibile, DLL o asset. `Install.cmd` è soltanto il patcher di questo add-on: non installa e non scarica la mod VR base.**

La mod base deve essere ottenuta e installata separatamente dal **[GitHub ufficiale di CircuitLord](https://github.com/CircuitLord/CircuitLordVRModInstaller)**.

- Ripristina la ricarica gestita dal gioco, senza dover inserire il caricatore o azionare l'otturatore a mano in VR.
- Nasconde il corpo del pilota lasciando visibili mani, armi e oggetti.
- Chiude e rifinisce i polsi delle mani, senza i lembi elastici del primo prototipo.

**“no_reload” nel nome significa niente ricarica manuale VR: non significa munizioni infinite e non elimina la ricarica del gioco.**

### Versione della mod base richiesta

| Questo add-on | 1.0.1 |

**1.0.25 è la versione della mod VR; 1.2.12 è la versione del programma che la installa. Sono due numeri diversi.** Usare l'installer 1.2.12 non garantisce da solo che sia installata la mod corretta: selezionare Titanfall2VR 1.0.25 e controllare la versione effettivamente installata.

Installare prima il gioco e la mod base, quindi avviare la campagna VR almeno una volta e verificarne il funzionamento.

Per la mod base e il suo installer usare esclusivamente il **[repository GitHub dell'autore](https://github.com/CircuitLord/CircuitLordVRModInstaller)**, nella sua sezione Releases. Non sono ospitati o allegati in questo progetto.

Il patcher verifica anche l'hash SHA-256 esatto della DLL e dei due modelli originali. Se i file sono diversi, si ferma invece di provare a modificarli. **Non è compatibile automaticamente con altre versioni, beta o DLL già modificate.**

### Installazione

1. Scaricare questo progetto con **Code → Download ZIP** ed estrarlo completamente.
2. Chiudere Titanfall 2.
3. Eseguire **Install.cmd (il nostro patcher, non l'installer di CircuitLord)** e incollare il percorso della cartella che contiene `Titanfall2.exe`.
4. Attendere il messaggio di completamento, poi avviare il gioco tramite il consueto launcher VR.

Richiede Windows 10/11 **x64**, PowerShell 5.1 o successivo e una connessione Internet al primo avvio. Non serve installare Python o Node.js a livello di sistema: lo script scarica copie portabili e librerie open source, con versioni e checksum bloccati, nella cartella locale dell'utente. Non modifica il PATH di Windows e non richiede normalmente privilegi di amministratore.

**Check.cmd** verifica la compatibilità senza modificare il gioco. Al primo utilizzo può scaricare il solo runtime Python.

La modifica viene applicata al profilo `TF2VR`. Il patcher salva una copia della DLL originale e una ricevuta locale in:


I modelli generati localmente vengono installati come mod separata:

```text

```

### Ripristino

Chiudere il gioco ed eseguire **Uninstall.cmd**, indicando la stessa cartella. Ripristina la DLL originale e rimuove i soli file generati da questo add-on. Se trova file aggiornati o modificati in seguito, interrompe il ripristino per non sovrascriverli.

Non cancellare la cartella di backup prima del ripristino. Le copie portabili dei runtime rimangono in `%LOCALAPPDATA%\titanfall2mod_no_body_no_reload\runtime` e possono essere rimosse manualmente quando non servono più.

### Cosa viene distribuito

Questo repository contiene **codice del patcher, istruzioni, checksum e documentazione**. Non contiene la DLL della mod VR, eseguibili della mod, modelli del gioco, texture o archivi VPK, né completi né modificati.

Il nostro patcher legge la DLL e gli archivi VPK già presenti sul PC dell'utente, genera le modifiche sul posto e crea backup esclusivamente locali. Non scarica l'installer di CircuitLord, la sua mod VR o i modelli, da questo repository o da altri siti. I soli download automatici sono strumenti open source elencati in `runtime-lock.json`. Non caricare su GitHub i file generati, i backup o le cartelle temporanee.

La ricarica automatica modifica tre chiamate della DLL compatibile. La modalità solo mani viene generata dai due modelli locali del pilota; posizioni e pesi dei soli bordi dei polsi vengono rifiniti per mantenerne la chiusura durante l'animazione.

- Provato su una specifica installazione di Titanfall2VR 1.0.25 e sui due modelli identificati in `compatibility.json`.
